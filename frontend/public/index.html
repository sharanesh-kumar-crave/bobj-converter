BW System Assessment

Connect to SAP BW or upload exported assessment files to analyse your BW landscape

📂 Upload BW Assessment Files

Run the BW Assessment SQL scripts in transaction DB02 or DBACOCKPIT, download results as Excel, and upload all three files below. View SQL guide ›

📋
Base Tables
*Base.xlsx — BW object inventory
📈
Stats Tables
*Stats.xlsx — usage statistics
💾
Table Volumes
*Volume.xlsx — memory & disk (HANA)
SQL Execution Steps ✕
  1. Log in to SAP BW via SAP Logon
  2. Run transaction DB02 or DBACOCKPIT → SQL Editor
  3. Paste the Base SQL → set limit to 1,000,000 → Excel Download → save as Base Tables.xlsx
  4. Paste the Stats SQL → Excel Download → save as Stat Tables.xlsx
  5. Paste the Volume SQL (HANA only) → Excel Download → save as Volume.xlsx
  6. Upload all three files above and click Analyse
